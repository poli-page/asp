## Versioning

`PoliPage.AspNetCore` shares its major.minor with the Poli Page API: package `0.13.x` talks to API `0.13` and requires the `PoliPage` SDK `[0.13.0,0.14.0)`. Patch numbers are free: a fix to the package alone is a patch. A change of the API contract, a new feature, and a raise of the minimum .NET or ASP.NET Core version are each a minor.
